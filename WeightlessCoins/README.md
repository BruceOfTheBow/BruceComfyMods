# WeightlessCoins

Coins as light as feather... lighter, actually.

## Instructions

Installing the mod will make coins weightless. Using the BepInEx Configuration Manager allows setting a coin 
weight scale, if *some* weight is desired. Scale factor multiplies the coins weight by a percentage. A scale factor of
0.5 means coins will weigh 50% of their vanilla weight. Allowable scale factors are 0.0 to 10.0.
