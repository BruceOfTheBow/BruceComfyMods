# SnapPointsByComfy

*Snap Points by Comfy. A replacement for Snap Points Made Easy.*

## Snap Behavior

  * Enable mod with hotkey (Right Control by default).
  * Toggle between two snap modes, Cycle and Closest (CapsLock by default)
  * On Cycle mode, cycle between each snap point on the source and target piece
    * Source (Piece being placed) snap point cycle with left control by default
    * Target (Piece under your crosshairs) snap point cycle with left alt by default
  * Additional configuration option to disable the default snap point for each piece
    * For any prefab without vanilla snap points, you will no longer be able to snap to these pieces
